# Análise Exploratória do Dataset Airway

Projeto-zero do meu portfólio de bioinformática. Análise exploratória de dados de RNA-seq de células de músculo liso de via aérea humana tratadas com dexametasona.

## Pergunta biológica

As amostras tratadas com dexametasona se separam das amostras controle em uma análise exploratória de expressão gênica?

## Dataset

`airway` (Bioconductor) — 8 amostras, 63.677 genes. 4 linhagens celulares, 2 condições (tratado/controle).

Referência: Himes et al., 2014. PMID: 24926665.

## Estrutura do projeto

- `R/` — scripts de análise
- `reports/` — relatórios em RMarkdown
- `figures/` — figuras exportadas
- `data/` — dados (carregados via Bioconductor, não armazenados aqui)
